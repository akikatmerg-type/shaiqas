# SHAIQAS — версия для Unity (перенос из PWA)

Эта папка — перенос браузерной игры SHAIQAS на движок Unity 6.
Всё подготовлено заранее: данные, графика, код на C#, настройка проекта.
Остаётся открыть проект и нажать ▶ Play.

## Как запустить (≈15 минут, один раз)

1. **Установи Unity Hub** → вкладка *Installs* → *Install Editor* → **Unity 6 LTS** (6000.0.x).
   Если будешь собирать игру на телефон, отметь модуль *Android Build Support*.
2. **Скачай проект.** На GitHub: *Code → Download ZIP* (или `git clone`), распакуй.
   Нужна папка `unity/SHAIQAS`.
3. **Открой проект.** В Unity Hub: *Projects → Add → Add project from disk* → выбери папку
   `unity/SHAIQAS` → выбери версию Unity 6 LTS. Первое открытие занимает 3–8 минут: Unity
   импортирует около 600 картинок.
4. **Проект настроится сам.** При первом открытии скрипт `ShaiqasSetup`:
   - создаёт материал бойцов;
   - создаёт сцену `Assets/Scenes/Main.unity` и добавляет её в сборку;
   - ставит горизонтальный экран и разрешение 1280×720;
   - настраивает импорт картинок.

   Повторить настройку вручную: меню **SHAIQAS → Setup Project**.
5. **Нажми ▶ Play.** Откроется ввод имени, потом лобби.

> Если в консоли (Console) появятся красные ошибки — это нормально для первого запуска
> кода, который ещё ни разу не компилировался настоящим Unity. Пришли их Claude (или подключи
> MCP, см. ниже): исправление занимает минуты.

### Для работы Claude без остановок (MCP for Unity)
1. В Unity: *Window → Package Manager → + → Add package from git URL* →
   `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main`
2. *Window → MCP for Unity → Configure All Detected Clients* (нужен Python 3.10+ и `uv`).
3. Открой этот чат в приложении Claude на компьютере и привяжи компьютер.
   После этого Claude сам видит консоль Unity, запускает игру и исправляет ошибки.

## Что перенесено (версия 1)
- **Весь контент:** 9 глав, 251 страница сюжета с иллюстрациями, сцены перед боями и после
  них, диалоги с историческими героями (+15 теңге за верный ответ), эпилог, «Есте сақта»,
  36 карточек альбома, все вопросы викторин (казахский + русский перевод).
- **Цепочка кампании как в вебе:** сюжет → бой → следующий бой → конец главы →
  викторина (6 из 8, в детском режиме 5) → открывается следующая глава.
  Главный босс — до 3 выигранных раундов.
- **Бой:** перенесена логика бойца из веба:
  - позы (45), анимация на пружинах, походка;
  - комбо, рывок, прыжок, удары в воздухе, присед;
  - блок, бросок, падение и перекат, удар духа (рух), волна;
  - ИИ врага, вторая фаза босса, усиление врагов по главам.
- **Внешний вид бойцов:**
  - тело рисуется теми же формулами, что в вебе;
  - голова, шапка и оружие взяты картинками прямо из веб-движка;
  - работают все 64 256 сочетаний «герой × броня × шапка × оружие».
- **Экраны:**
  - ввод имени;
  - лобби, карта глав со звёздами, сюжет;
  - викторина, альбом, медали;
  - магазин с требованиями уровня, герои, настройки;
  - наставник Бухар-жырау, всплывающие награды.
- **Сохранение** (PlayerPrefs), **уровни и опыт**, медали (включая «Тарихшы» за все 36 карточек).
- **Кинокамера:** зум, кинополосы, тряска; тень и контурный свет бойцов, искры и пыль.

## Что добавлено в версии 2 (ноябрь 2026)
- **Звук и музыка:** 58 эффектов и 31 кюй, отрендерены из веб-движка звука.
- **Живые арены:** облака, лучи солнца, туман, флаги на ветру, дым, костры, птицы, всадники,
  караваны, частицы (пыль, снег, листья, угли), фоновая битва войск, пост-обработка (bloom,
  цветокоррекция, зерно). Картинка сверена с вебом попиксельно.
- **Режимы:** турнир (сетка на 8, экран VS), выносливость, дуэль с рейтингом, нашествие главных
  врагов, способности боссов, свободная арена (тренировка приёмов).
- **18 приёмов (әдістер):** ввод последовательностями, снаряды, статусы, клон-аруақ, книга приёмов,
  баннер нового уровня.
- **Ткань:** пояс и подол развеваются (цепочки с инерцией, как в вебе).
- **Экраны в стиле веба:** лобби, карта похода 2.0, сюжет, бой (HUD, пауза, итог), герои,
  оружие, альбом, викторина, награды, настройки.

## Что ещё не перенесено
1. Кисти на шапках и копьях (перья, сәлде, шашақ) — шапки и оружие пока картинки.
2. Детский режим: подсказка «!» перед ударом и приём одной кнопкой U.
3. Сборка APK для Android и проверка на телефоне.

## Отладка в редакторе (только Unity Editor)
- **F12** — снимок кадра в папку `Shots/` (для сравнения с вебом по пикселям).
- **F11** — по очереди выключает группы слоёв арены (поиск, какой слой портит картинку).
- **F10** — все приёмы открыты и дух всегда полон (проверка приёмов).

## Призрачный Юнити (проверка без Unity)
В облаке нет Unity, поэтому код проверялся «призраком» (`unity/ghost`):
- **ядро игры (`Assets/Scripts/Core`)** переводится в Java, компилируется `javac` и реально
  играет: 36 боёв ИИ против ИИ, сюжет, викторина, замки глав, сохранение;
- **призрачный рендер** рисует бойцов из того же C#-кода и сравнивает с веб-версией (совпадает);
- **линтер** (`lint.py`) и **проверка ссылок** (`refcheck.py`) ищут в Unity-слое ошибки, которых Java не видит:
  - числа без `f`;
  - повторные имена переменных во вложенных областях (CS0136);
  - провал между `case`;
  - несуществующие члены ядра;
  - неизвестные вызовы Unity API.
- **проверка файлов:** каждая картинка, которую запросит игра, существует.

Запуск: `cd unity/ghost && ./build.sh` (нужны Java 17+, Python 3 и `pygments`).

## Структура
```
unity/
  SHAIQAS/                 — проект Unity (открывать эту папку)
    Assets/Scripts/Core    — логика игры, без Unity (проверяется призраком)
    Assets/Scripts/Game    — экраны, бой, ввод (Unity)
    Assets/Scripts/Platform— U.cs: строки/числа/случайность для Unity
    Assets/Scripts/Editor  — автонастройка проекта
    Assets/Shaders         — шейдер атласа бойцов
    Assets/Resources/Data  — весь контент в JSON (выгружен из веб-игры)
    Assets/Resources/Art   — графика (выгружена из веб-движка)
  ghost/                   — призрачный Юнити (C#→Java, линтер, тесты)
  tools/                   — выгрузчики данных и графики из веб-версии (Playwright)
```
